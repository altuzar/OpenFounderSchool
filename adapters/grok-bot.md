# Grok Bot

Official entry point: [x.ai/bot](https://x.ai/bot). The page describes bots with tools and remote work. OpenFounderSchool adds educational context through text and files; it does not include a verified native import format.

## Preparation

An adult checks access, permitted age, and the current plan. Install or open the product from its official page. You do not need email, payment, calendar, or social connections to start. Use one dedicated bot with a functional name such as “OpenFounderSchool Coach.”

## Load the program

1. Unzip `release/openfounderschool-grok-bot.zip` locally; do not depend on the product reading ZIPs.
2. Open a conversation and paste `prompts/COACH.md` as working instructions. If persistent instructions are available, save them there and verify they apply in a new chat.
3. Attach `STARTER.md`. If folders or more files are supported, provide the overview, rubric, roles, and current week. Without attachments, paste STARTER.md into the conversation.
4. Run the shared acceptance check in adapters/README.md and confirm actual file access.
5. Begin week 1 with fictional data. Request a final checkpoint to save yourself or through authorized local writing.

## Boundaries

Do not create routines just because a channel demo shows them. Permanently communicating bots are unnecessary. Use coaching roles successively in one chat. Bots may share resources depending on product configuration: do not mix families' or customers' information expecting a bot name to isolate it.

If the model forgets instructions, reload COACH.md and the checkpoint. This is documented manual compatibility, not a successful test in your account. Check prices and conditions with the provider; the curriculum does not include a subscription.
