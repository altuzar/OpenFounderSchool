# Grok Bot

Ruta oficial: [x.ai/bot](https://x.ai/bot). La página describe bots con herramientas y trabajo remoto; el paquete de OpenFounderSchool aporta contexto educativo mediante texto y archivos. No contiene un formato de importación nativo comprobado.

## Preparación

Un adulto verifica acceso, edad permitida y plan vigente. Instala o abre el producto desde su página oficial. No es necesario conectar correo, pagos, calendario ni redes para empezar. Usa un bot dedicado al programa con un nombre funcional, por ejemplo “Coach OpenFounderSchool”.

## Cargar el programa

1. Descomprime `release/openfounderschool-grok-bot.zip` localmente; no dependas de que el producto pueda leer ZIPs.
2. Abre una conversación con el bot y pega `prompts/COACH.md` como instrucciones de trabajo. Si tu interfaz ofrece instrucciones persistentes, guárdalas allí y comprueba que se aplican al abrir otro chat.
3. Adjunta `STARTER.md`. Si admite carpeta o archivos adicionales, ofrece overview, rúbrica, roles y la semana actual. Si no admite adjuntos, pega el texto de STARTER.md en la conversación.
4. Ejecuta la prueba común de adapters/README.md y verifica qué puede leer de verdad.
5. Empieza con semana 1 y datos ficticios. Pide que entregue el checkpoint al final para guardarlo tú o mediante escritura local autorizada.

## Límites

No crees rutinas por seguir una demostración del canal. No hacen falta bots que se comuniquen de manera permanente. Los roles de coach se pueden usar sucesivamente en un solo chat. Los bots pueden compartir recursos según la configuración del producto: no mezcles información de familias o clientes esperando que el nombre del bot la aísle.

Si el modelo olvida instrucciones, vuelve a cargar COACH.md y el checkpoint. La compatibilidad documentada aquí es manual y no una prueba de funcionamiento en tu cuenta. Cotizaciones y condiciones se consultan al proveedor; el currículo no incluye la suscripción.
