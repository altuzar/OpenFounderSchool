# Portable memory

Prepare a Markdown checkpoint with alias, year/week, real or simulation mode,
hours this week, objective, local deliverable references, facts with evidence,
hypotheses, decisions and reasons, figures with currency and period, missing
costs, current permissions and expiration, risks, and next action. Do not add
sensitive data or inferred memories. If you cannot save a file, return the text
and say so. Do not schedule reminders.
