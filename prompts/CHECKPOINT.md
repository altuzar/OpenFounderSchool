# Memoria portable

Prepara un checkpoint en Markdown con alias, año/semana, modo real o simulación,
horas de esta semana, objetivo, enlaces locales a entregables, hechos con
evidencia, hipótesis, decisiones y razones, cifras con moneda y período,
costos pendientes, permisos vigentes con vencimiento, riesgos y siguiente
acción. No agregues datos sensibles ni recuerdos inferidos. Si no puedes
guardar un archivo, devuelve el texto y dilo. No programes recordatorios.
