# Portable kits

Download or copy your platform's ZIP. Unzip it first; not every assistant reads ZIP files.

- [Grok Bot](openfounderschool-grok-bot.zip)
- [Claude Project](openfounderschool-claude-project.zip)
- [ChatGPT Work](openfounderschool-chatgpt-work.zip)
- [Pi](openfounderschool-pi.zip)
- [Hermes](openfounderschool-hermes.zip)

Each kit includes `SETUP.md`, a combined-text `STARTER.md`, the full curriculum, guides, templates, and local tools. First load SETUP and STARTER; then add the current week and checkpoint. You do not need to upload everything at once.

`MANIFEST.json` contains file SHA-256 hashes. [SHA256SUMS](SHA256SUMS) contains ZIP hashes. Regenerate with `python3 scripts/ofs.py pack`. Kits are created locally without network calls or provider charges.

These are manual context adaptations, not official importers, plugins, or account installations. They include no student data, passwords, books, videos, or complete transcripts. If the assistant cannot access files, paste STARTER.md and the current lesson.
